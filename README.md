# WaveMusic
A simple plugin that will play music at wave spawned for SCP:SL, powered by [LabApi](https://github.com/northwood-studios/LabAPI)

## Dependencies
[AudioPlayerApi](https://github.com/Killers0992/AudioPlayerApi/)

## Config

```
ci_music: path/to/ci-music #if you want disable it, just let it empty or not valid
who_can_hear_ci_music:
- ChaosConscript
- ChaosMarauder
- ChaosRepressor
- ChaosRifleman
diable_ci_announcement: false
mtf_music: path/to/mtf-music #same
who_can_hear_mtf_music:
- NtfCaptain
- NtfPrivate
- NtfSergeant
- NtfSpecialist
diable_mtf_announcement: false
```
